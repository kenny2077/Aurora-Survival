# Source audit: SurvivalRobinson.docx

Audit date: 2026-07-23

## Classification

The attached 35-page document is a product architecture and implementation
plan. It is accepted as planning input for repository controls, architecture
decisions, experiment design, and acceptance gates.

It is **not** accepted as a runtime knowledge source. It does not establish
redistribution rights for the survival, medical, map, vehicle, or model
materials it discusses, and it is not a named expert attestation for any
procedure.

## Permitted use in this repository

- derive architecture decisions and checklist items;
- create schemas, tests, experiment matrices, and release gates;
- retain links as leads for a later source-owner license review.

## Prohibited use in production packs

- copying narrative into a field procedure merely because it appears in the
  document;
- treating a cited web link as permission to redistribute its content;
- representing the document as clinical, mechanic, wilderness, or legal review;
- marking a knowledge record `approved` without a separate source license and
  qualified reviewer attestation.

The generated `development_knowledge_pack.json` is synthetic and explicitly
test-only. Production pack ingestion must use the independent knowledge schema,
review attestation, source manifest, signed envelope, and recall process.
