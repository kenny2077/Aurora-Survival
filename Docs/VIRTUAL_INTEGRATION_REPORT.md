# Virtual integration milestone

The 2026-07-23 milestone described an earlier product contract. It was superseded on 2026-08-09 by the four-tab, two-tier redesign.

Current executable boundaries are recorded in `IMPLEMENTATION_STATUS.md` and `FIELD_MANUAL_PROGRESS_REPORT.md`. In particular, Ask now requires Lite or Expert, Maps is a dedicated tab, Tools is the two-tier model center, and readiness/trip/vehicle/OBD/status subsystems are retired.

Historical machine-readable evidence remains under `Reports/`; it must not be interpreted as acceptance of the current interface or removed capabilities.
