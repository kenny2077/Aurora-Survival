# Image attribution and licensing

The benchmark sources below were selected from Wikimedia Commons because each source page records a reuse license or public-domain status.
The downloader requests a Wikimedia-generated thumbnail (default width 1280 px) and saves it under an opaque Aurora test ID. No semantic edits are applied.

Before publishing the images outside an internal benchmark, re-check each linked source page because attribution/license metadata can be corrected over time.
